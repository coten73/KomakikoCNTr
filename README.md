# KomakikoCNTr
atrX的Komaki Won't Come to Class的汉化

包括Android **自用** 版本，**注意不要传播**
> **本仓库只存放发布信息与授权说明，不含汉化文件。**
> 请到 [**Releases**](../../releases) 页面下载。

## PC安装
1. 解压，把 `chinese_simp` 文件夹整个放进游戏的 `game/tl/` 目录
2. 启动游戏，然后就可以体验了

## Android安卓
直接安装，但注意此版本与官版版本不互通

## 出问题了怎么办
请到 `vx.kong@qq.com` 反馈，**请附截图**，并说明：
   - 游戏版本号
   - 问题出现在哪个界面
   - 注意标注来意
